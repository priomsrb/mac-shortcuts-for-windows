# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

Add user-facing changes under **Unreleased** as you go. `tools/release.ps1` moves them under the new version heading when a release is cut, and they become the GitHub release notes.

## [Unreleased]

\- Add a Custom page for recording your own shortcuts (any mix of Alt, Ctrl and Win + key → any key combination)

\- Custom shortcuts can be switched on and off or removed, and take priority over built-in shortcuts that use the same keys

\- Add an "Ignore keys from other apps" setting (on by default) so shortcuts aren't applied to keys sent by other tools such as PowerToys
